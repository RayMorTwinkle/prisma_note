# Prisma Note 项目重构计划

## 目标
优化项目结构，提高代码可维护性、可扩展性和可读性。

## 重构内容

### 1. 创建新的目录结构
- 创建 `lib/constants/` - 存放常量（颜色、尺寸、字符串等）
- 创建 `lib/utils/` - 存放工具类（日期格式化、文件操作等）
- 创建 `lib/theme/` - 存放主题配置
- 创建 `lib/routing/` - 存放路由配置
- 创建 `lib/widgets/sheets/` - 存放底部弹窗组件
- 创建 `lib/widgets/cards/` - 存放卡片组件

### 2. 拆分 main.dart
- 提取 AppRouter 到 `lib/routing/app_router.dart`
- 提取 MainScaffold 到 `lib/widgets/main_scaffold.dart`
- 保留应用入口和 Provider 配置

### 3. 移动子组件到 widgets 目录
- TimelineItemCard → `lib/widgets/cards/timeline_item_card.dart`
- SearchSheet → `lib/widgets/sheets/search_sheet.dart`
- ProjectGrid → `lib/widgets/project_grid.dart`
- TasksYearViewSheet → `lib/widgets/sheets/tasks_year_view_sheet.dart`
- ContactsListSheet → `lib/widgets/sheets/contacts_list_sheet.dart`
- QuickInputSheet → `lib/widgets/sheets/quick_input_sheet.dart`
- RecordingOverlay → `lib/widgets/recording_overlay.dart`

### 4. 创建主题配置
- `lib/theme/app_theme.dart` - 统一的主题配置
- `lib/constants/app_colors.dart` - 颜色常量
- `lib/constants/app_text_styles.dart` - 文本样式常量

### 5. 创建工具类
- `lib/utils/date_utils.dart` - 日期格式化工具
- `lib/utils/string_utils.dart` - 字符串工具

### 6. 优化 Provider 和 Service
- 保持 AudioRecorderService 在 services/，移除 providers/ 中的重复引用
- 优化 TimelineProvider，保持职责清晰

### 7. 更新导入语句
- 重构后更新所有相关文件的导入语句

## 预期效果
- 更清晰的目录结构
- 更好的代码组织
- 减少代码重复
- 提高可维护性
